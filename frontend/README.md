# ShareHouse web

React 18 + Vite + Tailwind client. See the root README for running the full stack.

```bash
npm install
npm run dev
```

Set `VITE_API_URL` in production to the public API origin (e.g. `https://sharehouse-yv9s.onrender.com`). Leave it empty in local dev so Vite can proxy `/api` to `http://localhost:5000`.
